### Added
- Connect a Seafile account through Seafile's own sign-in page, also with single sign-on (OAuth, SAML); the token stays on the webmail server
- Connect with a Web API token where the server doesn't offer the sign-in through the browser
- Attach files from your libraries, or share them as links with a password and an expiry date
- Offer to send large attachments as a Seafile link, uploaded in pieces that resume
- Save attachments and whole messages to a library
- A Seafile page to browse, search, upload, download and share files
